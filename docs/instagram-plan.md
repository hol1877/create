# 인스타그램 수익화 계정 — 테스트 계획 (2026.11~12)

> 근거: [`saju-profile.md`](saju-profile.md). 조건: 회사 재직 중, 주말만 운영, 얼굴 비노출(손·목소리까지), 회사 관련 스킬 미사용.

## 1. 테스트 계정 2개

| | **A. 요리 보초** | **B. 손등 발색 노트** |
|---|---|---|
| 콘셉트 | 좁은 주방의 요리 초보. 튀고, 설거지 쌓이고, 실수하는 과정을 **숨기지 않고 다 담는** 살짝 돌아있는 톤 | 립 신상·인기템을 손등에 나란히 발색 비교. **처음엔 립 한 카테고리만** |
| 포맷 | 손+목소리 릴스(30~45초), 자막 드립 + 고정 시리즈 카드 | 손 클로즈업 릴스(15~20초) + 비교 카드 |
| 고정 시리즈 | "레시피 vs 현실" / "피해 상황 리포트"(설거지 개수·튄 범위·소요 시간·성공률) / NG 모음 | 신상 발색 / 비슷한 색 비교 / 가격대별 |
| 수익 | 초보용 주방템 제휴(튐 방지망·실리콘 도구 등), 밀키트 협찬("초보가 도전" 포맷과 잘 맞음) | 뷰티 제휴 링크, 협찬 |
| 촬영 | 요리 1회 → 3편. 폰은 삼각대 고정 | 동쪽 창 오전 자연광, 고정 자리 (색 정확도 + 木 시간·동쪽) |
| 비용 | 식재료는 원래 생활비 (기록만) | 제품 구매 **월 5만원 상한**, 1주차는 보유 제품만 사용 |

**A가 프로파일과 맞는 점**: 실수가 곧 콘텐츠라 "과하게 다듬다 못 올림"(편인+현침살)이 원천 차단됨 → 80% 규칙이 저절로 지켜짐. 말로 어필하는 대신 자막 템플릿과 고정 시리즈 포맷이 캐릭터를 대신함(상관 0% 보완). 좁은 주방은 약점이 아니라 콘셉트의 일부.

## 2. 주간 루틴 (상한: 하루 8시간 절대, 주당 9시간 목표)

| 시간 | 할 일 |
|---|---|
| 토 08:00–10:00 | B 발색 촬영 (3편 분량 한 번에) |
| 토 10:00–13:00 | A 요리 도전+촬영+정리 (**3시간 넘으면 그 자리에서 종료**) |
| 토 14:00–16:00 | 편집 (템플릿) |
| 일 2시간 | 편집 마무리, 수치 기록 10분, 다음 주 주제, 예약 게시 |

- 게시: 두 계정 모두 **월·수·금 20:00 예약** (인스타그램 예약 게시 / Meta Business Suite)
- 일요일 예약 완료 후 준헌에게 "예약 완료" 인증 → 외부 마감 장치
- 완료 기준: 템플릿에 넣고 자막 오탈자만 확인하면 발행 (80% 규칙)

## 3. 1주차 콘텐츠 (11/9~11/13 게시분)

**A. 요리 보초** — 요리 1회 촬영으로 3편
1. 월: "레시피 vs 현실" 첫 도전 릴스 (예: 계란말이)
2. 수: "피해 상황 리포트" 카드 — 설거지 n개, 튄 범위, 소요 시간, 성공률 % (시리즈 고정 템플릿)
3. 금: NG·실수 모음 릴스 (자막 드립)

**B. 발색** — 보유 립으로 촬영
1. 월: 가을·겨울 MLBB 립 5종 손등 발색 릴스
2. 수: "비슷해 보이는 3종, 이렇게 다르다" 비교 카드 (저장형)
3. 금: 1만원 이하 립 발색 릴스

## 5. 기록 (일요일 10분)

게시물별: 조회수, 저장, 공유, 댓글, 팔로워 증감, DM 문의 수, 제작 시간 / 주별: 지출(발색 제품)

- 지출은 **발색 전용 체크카드 1장**으로만 결제 → 내역이 자동으로 남게

## 6. 12/20 결정 기준 (우선순위 순)

1. 게시물당 저장 + 공유
2. 팔로워 증가 속도
3. DM·문의 수 (제품·레시피 문의 = 수익화 신호)
4. 실제 제작 시간 (덜 지치는 쪽 가산점)

## 7. 멈춤 규칙

- 8시간 초과 주가 2주 연속 → 계정당 주 3편 → 2편
- 재고 0편 → 그 주는 쉼 (당일 제작·게시 금지)
- A 요리+정리가 3시간 초과 → 다음 주는 더 간단한 메뉴
- 12/20에 둘 다 기준 미달 → 주제 유지, 포맷만 바꿔 4주 추가
- 발색 지출이 월 5만원 도달 → 그 달은 보유 제품·재활용 콘텐츠만

## 8. 안전 (백호대살: 무리하면 탈 남)

- 기름 튀는 요리는 뚜껑·튐 방지망 필수, 화상 연출 금지
- 불 앞에서 폰을 손에 들고 찍지 않기 (삼각대 고정)
- 칼질 클로즈업은 천천히 찍고 편집으로 빠르게
