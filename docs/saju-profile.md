  - 생시 乙未(을미) — 편재 / 편인
  - 생일 辛丑(신축) — 일간 / 편인  ← **일간 辛金(신금), 일지 丑(축토)**

  - 생년 乙亥(을해) — 편재 / 상관

- 십성 분포: 편인 37.5% · 편재 25% · 비견 12.5% · 식신 12.5% / **관성(정관·편관) 0%, 상관 0%, 정재 0%, 겁재 0%**

## 2. 강점 (계정 운영에 쓸 것)

| 근거 | 강점 |
|---|---|
| 편인 37.5% | 한 주제를 끝까지 파고듦. 리서치·분석·구조 설계 탁월 |
| 현침살 + 辛金 | 디테일 포착력, 정밀함. 편집·썸네일·자막 퀄리티 관리에 유리 |
| 천문성 | 직관·통찰. 사람 심리와 반응 흐름을 읽음 |
| 화개살 3개 | 혼자 깊이 몰입하는 시간에 성과가 나옴 |
| 편재 25% | 돈·기회·시장 감각. 수익화 구조를 보는 눈 |
| 토 37.5% | 꾸준히 쌓는 힘. 장기 운영에 유리 |
| 태극귀인 | 도움을 **요청했을 때** 귀인이 작동 |

## 3. 약점 (설계로 보완할 것)

| 근거 | 약점 | 보완 장치 |
|---|---|---|
| 관성 0% | 스스로 마감 못 침. 외부 압력 없으면 미룸 | 예약 게시, 고정 요일, 준헌과의 약속으로 강제 |
| 상관 0% | 밖으로 드러내는 힘이 약함. 자기 어필 못 함 | 포맷을 템플릿화해 "표현"을 시스템으로 대체 |
| 화(火) 0% | 추진력·열정이 잘 안 붙음. 시작을 미룸 | 재고(미리 찍어둔 편수)로 시작 장벽 제거 |
| 토 37.5% 과다 | 분석이 실행을 잡아먹음. 결정 지연 | 결정에 데드라인 명시, "일단 올리고 고치기" |
| 정재 0% | 수익·비용 관리 시스템이 약함 | 가계부 아닌 **자동 기록** 구조 필요 |
| 겁재 0% | 경쟁·협업 근육 약함. 남 일을 떠안음 | 역할 문서화, 선 긋기 |
| 백호대살 | 무리하면 탈 남 | 주당 투입 시간 상한 설정 |

## 4. 현재 운세 흐름

- **2026년 丙午(병오)년**: 대운 丙火(병화) + 세운 丙午 → 관성 이중. 압박 최대. 외부 요구가 많고 소진되기 쉬운 해
- **2026년 11월 己亥(기해)월**: 亥(해)가 년지와 동일, 亥 중 甲木(갑목)이 용신 자극 → **실행 기운이 살아나는 달. 론칭 적기**
- **2027년 丁未(정미)년**: 편관+편인. 압력은 유지되나 생각이 더 많아짐. 일지 丑↔未 충(沖)으로 변동 활성
  - 2~4월: 용신 木 구간 → 상반기 최고 실행 구간
  - 5~6월: 압박 최대 + 변동 → 확장 금지, 유지·정비
  - 10~11월: 하반기 최고 구간 → 결정·확장

## 5. 계정 운영 원칙 (위 구조에서 도출)

1. **시스템 > 의지** — 관성 0%이므로 "열심히 하기"는 작동 안 함. 예약 게시·템플릿·고정 요일로 강제
2. **재고 우선** — 화(火) 0%라 시작 동력이 약함. 항상 1주치 이상 미리 확보
3. **완성도보다 발행** — 편인+현침살로 과하게 다듬다 못 올림. "80%면 올린다" 기준 명문화
4. **한 주제 반복** — 화개살·편인 구조는 좁고 깊은 쪽에서 성과. 주제 확장은 반응 확인 후
5. **혼자 시간 확보** — 화개살 3개. 편집·기획은 혼자 집중 블록으로 배치
6. **데이터로 판단** — 편재+천문성. 감이 아니라 저장·공유 수치로 결정
7. **역할 선 긋기** — 겁재 0%. "내가 하면 빠른데"가 함정. 준헌 몫은 넘기기
8. **도움 요청** — 태극귀인은 요청해야 작동. 막히면 외부(세무사·동종 크리에이터)에 묻기
9. **투입 시간 상한** — 백호대살. 주당 상한 정하고 초과 시 편수 줄이기
10. **멈춤 기준 명시** — 토 과다는 손절을 못 함. "이러면 포맷 바꾼다/쉰다" 기준 사전 정의

## 6. 용신(木) 활용 — 실무 적용

- 색: 초록·청록 계열 → 계정 톤, 썸네일 포인트 컬러 후보
- 방향: 동쪽 → 촬영 장소·작업 공간
- 시간: 아침(5~7시가 木 시간) → 기획·편집 집중 블록을 오전에
- 계절: 봄(2~4월) → 2027년 상반기가 확장 적기
- 숫자: 3, 8 → 주 3편 리듬은 구조와 맞음
