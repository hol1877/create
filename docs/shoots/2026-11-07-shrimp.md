# 요리 보초 — 생새우 촬영 기획 (2026-11-07 토)

## 스토리 축
- **"생새우 손질 3회차인데 아직도 이럼"**: 초보지만 세 번째라는 점을 숫자로 계속 보여줌 (다음엔 4회차)
- **"새우값 떨어졌대서 또 샀다"**: 구매 가격(100g당·팩당)을 그대로 카드에 기록. 지난번 가격을 기억하면 비교

| 메뉴 | 결정 | 이유 |
|---|---|---|
| 손질 | **메인** | 3회차 스토리의 핵심, 실수 장면이 가장 많이 나옴 |
| 갈릭버터새우파스타 | **메인** | 기름 튐, 설거지 많음 → 콘셉트에 딱 맞음 |
| 새우라면 | **엔딩** | 손질 후 남은 새우머리·껍질로 국물 → "버릴 게 없다" 엔딩 |

## 전날(금) 준비
- 새우 살 때 **가격표·영수증 사진** (100g당 가격이 보이게)
- 폰 2대 또는 폰+태블릿: ① 탑뷰 삼각대 (손 클로즈업) ② **와이드 고정 "피해 카메라"** (튐 범위·설거지 쌓이는 과정)
- 장갑 (새우 뿔 찔림 방지), 튐 방지망 또는 뚜껑

## 나올 콘텐츠 (3편 + 예비 1편)
1. **릴스: "생새우 손질 3회차인데 아직도 이럼"**
   - 첫 컷: 가격표 + "새우값 떨어졌대서 또 샀습니다"
   - 손질 실수 모음 → 마지막 "3회차 성공률 00%"
2. **카드: 피해 상황 리포트**
   - 새우 n마리 / 손질 시간 / 설거지 n개 / 튄 범위 / 총비용 / 1인분 단가 / 성공률
3. **릴스: 레시피 vs 현실, 갈릭버터 새우파스타**
   - 엔딩 쿠키: "머리는? 라면 됨" 새우머리 라면 5초
4. **(예비 재고) 새우머리 라면 단독 릴스** — 재고가 비는 주에 사용

## 자막 드립 예시 (80%면 발행)
- "3회차면 익숙해질 줄 알았죠"
- "새우가 저를 손질하고 있음"
- "버터 넣었는데 왜 제가 튀겨지죠"
- "설거지 n개. 새우는 6마리였습니다"
- "버릴 게 없다 (설거지 빼고)"

## 안전
- 새우는 **완전히 익혀서** 먹기 (김밥 편도 마찬가지)
- 손질 후 도마·칼·싱크대는 바로 세척
- 새우 뿔에 손 찔림 주의 → 장갑
- 기름 튀는 단계는 뚜껑·튐 방지망 사용, 화상 연출 금지
- 불 앞에서 폰은 손에 들지 않기 (삼각대 고정)
